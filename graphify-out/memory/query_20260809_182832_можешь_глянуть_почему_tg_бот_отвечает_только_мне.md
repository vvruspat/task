# Q: можешь глянуть почему tg бот отвечает только мне, а остальных чатовцев посылает? А еще глянь почему он имея доступ к истории сообщений никогда не пользуется ей

## Answer

Expanded from original query via graph vocab: [telegram, message, history, context, user, account, link, member, chat, agent, prompt, identity]. Telegram access is intentionally sender-scoped: handleTelegramMessage resolves the current sender Telegram ID, rejects telegram_user_unlinked, and the API also requires that linked tAsk user to be a member of the chat workspace. Therefore each participant needs an individual Telegram identity link and workspace membership. History storage and reading work, but AgentService passes only the current user message to the runtime. Commit 0ab4548 removed deterministic routing of referential requests such as обсуждали and история to telegram_history_read and now sends tool_choice auto, so the model may answer without invoking history. Tests mock the model tool call and therefore do not cover this real selection failure.
