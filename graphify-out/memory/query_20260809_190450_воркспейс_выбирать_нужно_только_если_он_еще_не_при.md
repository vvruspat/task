# Q: воркспейс выбирать нужно только если он еще не привязан к текущему чату

## Answer

Готово: bare /connect creates a signed one-time Telegram browser login. After tAsk authentication, TelegramConnectService checks whether telegram_chats already contains the current chat. If it does, the workspace is fixed, no selector is returned, membership is checked, and only the sender identity is linked. If it does not, the UI shows only Telegram-enabled workspaces where the user is owner or admin, then connects the chat atomically. The legacy /connect token flow remains supported.
